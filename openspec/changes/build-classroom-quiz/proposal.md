# Proposal

## Why

教師需要在同一份 Guided Notes 上帶領全班分組搶答，並能解釋每題由誰先答、何時截止、哪些結果已公布，以及答案實際寫回哪兩格。第一輪以同一批請求與同一份工作表的可觀察結果作為共同驗收依據。

## What Changes

- 教師登入、建場並公告活動加入碼。學生以組長或組員身分加入，準備中與開放中均可建組，開放中新組取得下一公開代號並增加監看總組數。同組裝置共用每題的一次提交資格。
- 教師選定雲端試算表分頁，預覽單題題號與總題數後整場開放；學生依課堂學習單自行選題、逐題送出。
- 伺服器按完整請求收件序處理開場、送答與截止。教師監看各組，學生在截止前只取得本組資訊。
- 截止確定並公開勝組；教師確認個別題目才公布該題勝答。回寫原表的「作答」與「搶答勝組」兩格，保留整格格式、合併範圍及非目標格。同分頁重疊目標跨場序列化；重試時核對雙格及覆蓋同意。
- 以第 37 題串起雙角色、收件、結算、公布與回寫。題組、CSV、公平順位留待第二輪；第一輪依格式與身分判定有效性，知識正確性由教師課堂檢討。

## Capabilities

### New Capabilities

- `classroom-session`：教師與組別身分、場次建立、開放與結束、跨場隔離及重新加入。
- `guided-notes-import`：分頁選擇、單題辨識、匯入檢查及本場題目版本。
- `quiz-adjudication`：完整收件順序、首次有效作答、原收據、截止結算及持久保存。
- `classroom-results`：短輪詢、教師監看、學生資料邊界、逐題勝答公布。
- `guided-notes-writeback`：逐題預覽、兩格精確定位、純文字寫入、衝突及失敗復原。

## Impact
