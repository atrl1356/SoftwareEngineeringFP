# Proposal

## Why

教師需要整理誤建或已用完的活動，也需要在移錯場時找回名冊與結果。只從畫面隱藏一列，學生仍可能從舊頁讀回答案，排隊中的工作也可能再寫入共用學習單。建組與開場另有兩項課堂需求：檢查組長學號，以及讓教師在零組時確認是否開場。

## What Changes

- 「我的活動」提供逐場及勾選多場移除。確認畫面列出名稱、活動碼、階段與十天還原期限。伺服器逐場檢查擁有者和當下資格，混選時只處理已確認且符合資格的場次。
- 準備中可移除，包含已有組別等待的場次。開放中須先截止。已結束須每題雙格已核實或無勝組略過，且沒有排隊或執行中的回寫。移除、還原與清除對 Google Sheets 寫入零次。
- 原教師可在移除成功後 240 小時內從「已移除」還原。準備中還原保留原組，由原教師取得新活動碼及每組新碼，分別交給對應組長。已結束還原後，學生可用原活動碼與原組內碼重新加入，查本組收據及已公布結果。原名冊、答案與順位保留，場次不重開。到期自動清除該場本地紀錄。
- **BREAKING** 新建組的學號須為以 `1` 開頭的九位半形數字。保留舊名冊、原組的身分恢復方式與公開代號。
- 匯入有效但已成立組數為零時，教師須再確認才開場。已有組別時仍只需單擊。正式開場繼續與送答、截止共用完整請求順位。

## Capabilities

### New Capabilities

- `activity-retention` 管理移除資格、逐場與批次操作、原教師還原和十天到期清除。

### Modified Capabilities

- `classroom-session` 調整建組學號、還原後的進場資格與零組開場。
- `classroom-results` 學生頁辨識活動已移除，停止輪詢並清除先前畫面。
- `quiz-adjudication` 送答重試與原收據查詢均須核對當前存取資格。
- `guided-notes-import` 匯入與重選版本跨越移除時，舊讀取結果不能寫回場次。
- `guided-notes-writeback` 在移除與回寫並發時維持逐題資格，保留跨場使用的儲存格版本。

## Impact

依據為 `main` 的 `5fe506c`、第 43–49 題，以及第 3、14–17、23–29、32–39 題的既有行為。第一輪五份規格仍位於 [build-classroom-quiz](../build-classroom-quiz/specs/)。正式同步規格時，應先同步第一輪，再套用本次差異。

沿用 Vue 3、Fastify、SQLite、Google Sheets API 與既有測試工具。影響教師列表、學生進場與輪詢、收據、SQLite 遷移與定時清理，以及匯入、回寫的重啟復原。本版已取得使用者的實作核准，詳見[審查紀錄](review.md)。
