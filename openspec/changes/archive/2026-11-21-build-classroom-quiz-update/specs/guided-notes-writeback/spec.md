# Spec Delta

## ADDED Requirements

### Requirement: 移除與跨場回寫的隔離

系統 SHALL 依本場已保存的逐題雙格核實結果與仍在排隊或執行的工作決定移除資格。移除、還原、到期清除皆不得向 Sheets 寫入。保留其他場次辨識重疊寫入所需的版本，失效的確認、重試與重啟工作不得再寫原表。（第 30–36、42、44–46、49 題）

#### Scenario: 排隊、執行、逾時與覆核

- **GIVEN** A 與 B 共用分頁，A 的工作等待 B 釋放分頁，或 A 正在等 Google 的確認回覆
- **WHEN** 教師嘗試移除 A，再分別模擬逾時結果未知、僅一格符合、撤權失敗或新衝突
- **THEN** A 保持可管理且列出未結案題目。須按原規則重新定位兩格並核對型別、版本及同意。全部有勝組題都已核實、其餘題略過且沒有未完成工作才可移除。

#### Scenario: 重啟或清除後另一場仍能發現衝突

- **GIVEN** B 已預覽，A 隨後完成對至少一個重疊格的寫入，兩場的預計文字可以相同
- **WHEN** 移除 A，重啟並重送 A 的舊確認或重試，再讓 A 到期清除，最後以 B 的舊預覽確認
- **THEN** A 的生命週期操作及舊工作新增寫入零次。B 仍須取得新預覽與同意，兩格保留當前值。若另外在期限內還原 A，也不能藉舊確認再寫。

#### Scenario: 另一場後續改寫與無勝組

- **WHEN** A 已全題結案後 B 改寫同題，原教師移除 A，或移除另一場全題均無勝組的活動
- **THEN** 兩場均依本場已保存的結案紀錄判定。兩個目標格、其他儲存格與合併範圍維持移除前的狀態。
