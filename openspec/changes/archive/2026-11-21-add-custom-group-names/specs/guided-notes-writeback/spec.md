# Spec Delta

## MODIFIED Requirements

### Requirement: 逐格同意覆蓋並保存純文字

系統 SHALL 於教師解決兩格原值衝突、確認該題後，只將勝答原文以純文字寫入作答格；新建立場次將勝組名稱以純文字寫入勝組格，遷移前既有場次仍寫入原公開代號。保留目標格的整格格式、合併範圍及非目標格的內容與格式。目標格內的局部富文字樣式及內嵌連結不列入本輪保留範圍。無勝組時略過兩格。（第 29、31、32、36、41、42 題）

#### Scenario: 原有公式或不同文字
- **WHEN** 任一格的實際內容為不同原值或公式，即使公式顯示空白或與預計值相同
- **THEN** 並列原值與預計值，須教師對該格明確同意才覆蓋。空格可填，已符合的純文字可標為一致。第二場無勝組時，兩格即便有上場資料也保留原值。

#### Scenario: 整格格式及局部富文字
- **GIVEN** 目標格有底色、框線與數字格式，舊文字的一部分加粗並含連結，相鄰非目標格亦有富文字
- **WHEN** 教師確認以純文字替換目標格舊值
- **THEN** 核對讀回值、整格格式、合併範圍及所有非目標格（含其富文字）均符合預期；不以被替換目標文字的局部加粗或連結作為通過條件。

#### Scenario: 文字型別與公開代號
- **WHEN** 分別回寫勝答 `001`、`=1+1` 及含首尾空格的文字
- **THEN** 讀回作答格可取得完全相同的字串與空格，前導零保留且沒有公式；勝組格只含新場次的勝組名稱或舊場次的公開代號，沒有組長學號或任一種加入碼。

#### Scenario: 名稱寫回與舊場相容
- **WHEN** 教師確認新場次與升級前既有場次的勝組格寫回
- **THEN** 新場次讀回完全相同的組名文字，舊場讀回原 G 代號；兩者均保留整格格式與非目標格。
